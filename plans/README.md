# Implementation plans

Store implementation plans here before starting non-trivial work.

## Naming

Use descriptive filenames with a date prefix, for example:

```
plans/2026-08-24-user-authentication.md
plans/2026-09-01-recipe-search-api.md
```

## Suggested template

```markdown
# Plan: [Title]

**Date:** YYYY-MM-DD
**Scope:** frontend | backend | both
**Status:** draft | in progress | done

## Goal

What we are building and why.

## Out of scope

What this plan explicitly does not cover.

## Steps

1. ...
2. ...

## Open questions

- ...
```
